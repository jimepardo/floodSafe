# Flood System - La Plata

In 2013, the city of La Plata experienced a severe flood that continues to have repercussions to this day.

The goal of this project is to provide a platform where people can access information about evacuation centers, as well as report incidents, offer assistance, and resolve inquiries in case of future flooding events.

## Technologies Used
Python, Flask, and Vue.js.
